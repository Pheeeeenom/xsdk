The palette conversion's variants (vulkan4xenon's milestone 14), each drawn into the conversion's target and that
target dumped from memory, a new variant each 20 s, the four in a row in variants_*.png. The copy is the minimap's
EFB copy of 8-bit indices; the palette its 204 entries.

Set a, before any serialize bit, and with fetches alone serialized when they read a temp the ALU wrote in the exec:
  V0  vec4 index = floor(texture(source, in_uv) * 255.0 + 0.5);
      o_color = texture(palette, index.xx * upush.palette_scale.xy + upush.palette_scale.zw);   (the conversion)
  V1  o_color = texture(palette, in_uv);
  V2  vec4 index = floor(texture(source, in_uv) * 255.0 + 0.5);
      o_color = vec4(index.x / 255.0, index.x / 255.0, index.x / 255.0, 1.0);
  V3  vec4 index = floor(texture(source, in_uv) * 255.0 + 0.5);
      o_color = texture(source, index.xx * upush.palette_scale.xy + upush.palette_scale.zw);
